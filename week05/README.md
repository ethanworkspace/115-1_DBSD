## 作業W05 學習單（2 題）

**題目**：**（一）ER 圖**：把你的船舶資料設計成兩個實體 Ship 與 Voyage（一艘船的每一次進港靠泊是一筆 Voyage；你手上的 50 筆是攤平的，一艘船只記了一次）。手畫出兩個實體的屬性、主鍵 PK、Voyage 指回 Ship 的外鍵 FK、關係線，以及關係線**兩端的基數**，寫成 (最少, 最多)。先自己畫一版，再把同一題丟給 AI 要它也畫一版，逐項校正，**圈出至少一處你和 AI 不一樣的地方**並寫出哪一邊對、為什麼。**（二）SQL**：寫一句 SQL 算出你的資料中「靠泊時間 > 20 且船型 = 貨櫃」的筆數，與你在 Excel／phpMyAdmin 直接數的答案比對。

**資料**：「我的 50 筆」（已匯入 MySQL）。Voyage 不必真的建表，第（一）題只畫設計圖。

**繳交物**：第（一）題畫在本週**紙本學習單**上，含 AI 揭露三件（提示詞紀錄、AI 原始產出、修改對照），下課前交回紙本；第（二）題的 SQL 語句與結果截圖貼答題卡，附一句「和我自己數的一樣／不一樣」。

**評分要點（Pass／Fail）**：ER 圖有兩個實體、主鍵與外鍵都標出來、關係線兩端都寫了基數；有圈出一處與 AI 的差異並說明哪一邊對；SQL 語法正確且有做結果驗證。
