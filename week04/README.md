## 作業W04 學習單（1 題）

**題目**：下表為某船務用品店的訂單記錄，尚未正規化：訂單編號、客戶姓名、客戶電話、商品名稱、商品單價、數量。請完成三件事：（一）寫出至少兩項函數相依，格式 A → B；（二）指出違反第幾正規化並說明理由；（三）拆成符合 3NF 的多張表，寫出每張表的欄位與主鍵。

**資料**：題目表格在當週投影片最後一頁，共三列資料；不必建資料庫。

**評分要點（Pass／Fail）**：函數相依至少兩項且方向正確；指出違反的正規化層級並有理由；拆出的表每張都有主鍵。
